## Arquitectura del frontend

<div className="docSectionCard">
  <div>Estructura base dentro de <code>src/</code>:</div>
  <ul>
    <li><code>app/</code>: configuracion global, layouts, providers y rutas.</li>
    <li><code>entities/</code>: dominio y acceso a datos por entidad.</li>
    <li><code>features/</code>: casos de uso de UI.</li>
    <li><code>pages/</code>: composicion de pantallas.</li>
    <li><code>widgets/</code>: bloques reutilizables grandes.</li>
    <li><code>shared/</code>: utilidades transversales.</li>
  </ul>
</div>

## Flujo de autenticacion

<div className="docTimeline">
  <div className="docTimelineItem"><strong>1.</strong> Usuario inicia sesion o se registra.</div>
  <div className="docTimelineItem"><strong>2.</strong> Se guarda token en <code>localStorage</code> (<code>authStorage</code>).</div>
  <div className="docTimelineItem"><strong>3.</strong> <code>AuthHydrator</code> valida sesion en <code>auth/me</code>.</div>
  <div className="docTimelineItem"><strong>4.</strong> Si no hay sesion, se limpia estado y redirige a <code>/login</code>.</div>
  <div className="docTimelineItem"><strong>5.</strong> Si hay sesion, <code>useAuthStore</code> marca autenticacion valida.</div>
</div>

## API REST y SignalR

### Cliente HTTP

<div className="docSectionCard">
  <div>El cliente Axios en <code>src/shared/api/http.ts</code>:</div>
  <ul>
    <li>Usa <code>VITE_API_URL</code> como <code>baseURL</code>.</li>
    <li>Configura <code>withCredentials: true</code>.</li>
    <li>Agrega <code>Authorization: Bearer &lt;token&gt;</code>.</li>
    <li>Ante <code>401</code>, intenta refresh (<code>POST /auth/refresh</code>).</li>
  </ul>
</div>

### Tiempo real

<div className="docSectionCard">
  <div>La conexion SignalR en <code>src/features/chat/signalr/chat-hub-connection.ts</code>:</div>
  <ul>
    <li>Toma URL de <code>VITE_SIGNALR_URL</code>.</li>
    <li>Conecta a <code>/messages/chat</code>.</li>
    <li>Aplica reconexion automatica.</li>
  </ul>
</div>

## Rutas principales

| Ruta | Descripcion |
| --- | --- |
| `/` | Home publica |
| `/(auth)/login` | Login |
| `/(auth)/register` | Registro |
| `/_protected/chat` | Chat protegido |

## Variables de entorno

```env
VITE_API_URL=http://localhost:3000
VITE_SIGNALR_URL=http://localhost:3000
```

## Instalacion y ejecucion local

```bash
bun install
bun run dev
```
